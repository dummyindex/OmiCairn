# smoke-tiny — OmiCairn infrastructure smoke test

This is NOT a real biomedical research case. It exists solely to
verify that the OmiCairn pipeline runs end-to-end on a trivial
dataset. Its analysis outputs should be clearly labelled as a smoke
test in the REVIEW phase and should not claim real scientific value.

The data was generated by `generate_data.py` with random seed 42.
The true data-generating process is
`y = 1 if (feature1 + 0.5*feature2 + N(0, 0.6)) > 0 else 0`.
A well-calibrated logistic regression should achieve held-out AUC in
the range 0.80–0.90.
